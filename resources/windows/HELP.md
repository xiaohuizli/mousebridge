# MouseBridge Windows 应用 v0.3.1

## 安装和启动

1. 双击 `MouseBridge-0.3.1-windows-setup.exe`，按向导选择安装位置。
2. 安装程序自动选择本机 x64 或 ARM64 的原生程序，需要 Windows 10/11 的 64 位系统。
3. 默认安装到当前用户的 LocalAppData/Programs/MouseBridge，无需提升为管理员。开始菜单提供启动和卸载入口，Windows“已安装的应用”中也可卸载。
4. 双击开始菜单中的 MouseBridge 即可打开原生窗口，不会要求手填命令、IP、密钥或确认数字。

安装程序没有代码签名，Windows 可能提示来源未验证；请自行确认安装包来源。本地安装包未经过 Microsoft 商店发布或 Authenticode 签名。

另提供 x64 / ARM64 便携 ZIP。完整解压到同一文件夹后双击 `MouseBridge.exe`，不要只复制一个 exe；同目录的 `mousebridge-core.exe` 是内置核心程序。

## 局域网互控

- 在所有电脑上更新至 v0.3.1，打开“开启局域网发现与双向共享”。Mac / Windows 可以互相发现和共享鼠标。
- 开启即允许当前直接连接局域网内其他同样开启的软件连接并控制本机，没有首次数字确认或配对名单。
- 每台电脑同时具备控制和接收能力。两台时自动选中对方，多台时从“控制目标”列表切换，最多连接 16 台其他电脑。
- 将鼠标穿过所选桌面最外侧边缘进入目标电脑，Esc 或移回入口边缘返回本机。左侧/右侧表示目标在本机哪一侧；多显示器之间的接缝不会触发切换。更改显示器排列后请重新打开共享服务。
- 一个桌面同一时刻只接收一个远端鼠标，前一操作者返回或断线后，其他电脑可以进入。
- 关闭发现会断开全部远端会话。关闭窗口/退出时，通过关闭私有管道让核心正常释放鼠标并退出，不在后台持续运行。
- Windows 界面的发现开关和方向偏好保存在当前用户 AppData/Roaming/MouseBridge/preferences.json；这个文件只包含非敏感设置。身份密钥每次打开随机生成，只存在内存和子进程环境中，不保存到文件或凭据库。

若 Windows 防火墙提示 `mousebridge-core.exe` 的网络访问，请按当前局域网选择允许。软件不自动修改防火墙规则、不安装服务、不设置开机启动。访客 Wi-Fi 客户端隔离、不同 VLAN、VPN 路由或阻止广播会影响发现。使用 UDP 42049 发现和动态 TCP 端口通信。

Windows UAC 安全桌面、锁屏、权限更高的程序、不同交互会话不属于当前支持范围；本程序不自动提权。鼠标坐标覆盖全部显示器，键盘转发、剪贴板与文件传输未实现。

## 验证范围

x64 / ARM64 原生窗口与核心已经交叉编译，PE 架构、GUI 子系统、SHA-256、ZIP 内容和 NSIS 编译均检查。核心功能通过 Go 测试及三进程实际 TLS 网络验证；这些验证不捕获或注入操作系统输入。

实际验证范围以同次构建的检查报告为准。GitHub 的 Windows 安装包任务会执行静默安装、已安装核心的三进程网络验证和卸载；本地 macOS 交叉编译无法执行这些 Windows 检查。Windows 窗口交互、真实鼠标注入以及 Mac/Windows 实体机互控仍需真机验证，不能将 PE 检查或编译通过当作交互式桌面验收。

## 源码重建

需要 Go 1.25+、Python 3、NSIS 3.12+：

```sh
python3 scripts/package_windows_app.py
```

输出位于 `dist/windows-app/`，包含双架构安装程序、两个原生架构的便携 ZIP 与校验文件。
