# MouseBridge macOS 局域网互控 v0.3.2

原生 `.app`，支持 macOS 12+、Apple Silicon / Intel。无需安装 Go、Python 或使用终端。

## 同一局域网，打开即可互控

1. 所有电脑更新到 v0.3.2，双击 `MouseBridge-0.3.2-macos-universal.dmg`，把 `MouseBridge.app` 拖到 Applications 后打开。也可使用 ZIP 解压安装。
2. “开启局域网发现与双向共享”默认打开。首次也不需要数字确认、配对、填写 IP 或密钥。
3. 开启此功能即允许同一局域网内其他同样开启的软件自动连接并控制本机；本机也可以控制这些电脑。打开其他电脑时会自动出现在列表中。
4. 两台电脑时自动选中对方。多台电脑时，从“控制目标”列表选择要控制的电脑。接收其他在线电脑的控制始终保持可用，无需切换控制端/接收端角色。
5. 点击“启用鼠标权限”，按照 macOS 提示允许辅助功能和输入监控。系统若单独列出内置 `mousebridge` 程序，也应为实际程序授权。授权后重新打开应用或再次点击权限按钮。
6. 将本机鼠标穿过所选桌面最外侧边缘进入目标电脑；连接多块显示器时，显示器之间的接缝不会触发切换。按 Esc 或移回入口边缘返回本机。更改显示器排列后请重新打开共享服务。

数字确认已经完全从此 `.app` 移除。macOS 的系统隐私权限仍由用户授予，软件不会绕过系统权限。

## 多台电脑的行为

- 每台电脑同时保持接收能力和一个发送目标，可随时切换发送目标，切换时会释放旧目标上的鼠标按钮。
- 当前最多连接 16 台其他电脑。每一对电脑有独立的加密连接和临时输入通道密钥，首次自动协商，不持久保存设备白名单，也不受旧版已配对名单限制。
- 同一桌面同一时刻由一个远端鼠标操作。另一台电脑尝试进入时会自动返回本机；先前操作者返回、断线或退出后，其他电脑可以接管。
- 本软件注入的鼠标事件带标记，不会再被转发，防止多台电脑相互控制时产生事件回环。
- “左侧/右侧”表示当前发送目标在本机的哪一侧；按本机所有显示器组成的桌面最外侧边缘切换，支持显示器位于主屏左侧或上方的排列。
- 关闭发现会停止广播、拒绝新连接，并结束所有控制和接收会话，释放程序按下的鼠标按钮。下次打开会保留关闭状态；重新勾选后自动发现。
- 关闭窗口或退出软件会结束后台服务并释放端口。网络中断后自动恢复本机控制，发现仍开启时会自动重连。

## 网络与模式说明

开放发现使用 IPv4 UDP 42049，自动扫描当前可广播的网络接口；配对控制通道和鼠标输入通道使用动态 TCP 端口。请允许系统的本地网络访问及传入连接。访客 Wi-Fi 的客户端隔离、不同 VLAN 或阻止广播的网络会影响发现。

只向直接连接的局域网接口及回环地址建立开放连接；不会仅因为某个来源是私有 IP 就视为同一局域网。连接仍使用 TLS 1.3 加密，但开放模式不验证“用户已经批准此设备”这一身份关系；任何可访问该本地网络并实现协议的电脑都可能参与。界面的开启说明明确表示此授权范围。

公开广播包含电脑名、公开设备 ID 和端口，不含私密密钥。每次会话从 TLS exporter 派生临时输入密钥，断开即弃用。本机身份在每次打开应用时随机生成，仅存在内存及核心子进程环境中，退出即丢弃。此版本不读取或写入 macOS 钥匙串，也不将密钥写入项目、普通偏好配置或日志。旧版钥匙串条目不会被此版本访问或自动删除；设备白名单不生效。

命令行 `auto -open-lan` 提供同一开放模式，标准输入接受 `settings`（discover / enabled / edge）和 `select`（id）命令；标准输出提供设备列表与状态。未指定 `-open-lan` 的旧命令行审批模式为兼容保留，`.app` 始终使用开放模式。

## 签名与验证范围

使用本地 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；其他 Mac 可能需要允许打开可信的本地应用。本版没有钥匙串依赖；更新本地签名后，系统仍可能重新要求鼠标隐私权限。

自动化验证覆盖三台独立进程免确认发现、同时控制/接收、目标切换、关闭发现断开全部连接、重新发现、桌面输入互斥与按键释放。验证使用记录模式和实际 TLS 网络，不操作系统鼠标。跨多台实体 Mac 的鼠标、系统权限、Retina、缩放和触控板仍需真机验收；Intel 图形界面尚未完成交互验收；实际自动化检查以同次构建报告为准。

## 重新打包

安装 Go 1.25+ 和 Xcode Command Line Tools，在项目根目录运行：

```sh
python3 scripts/verify.py
python3 scripts/package_macos_app.py
```

DMG、ZIP 和 `.app` 产物位于 `dist/macos-app/`；三进程开放模式验证可单独执行 `python3 scripts/smoke_open.py`。
