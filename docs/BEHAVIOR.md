# 行为清单：原程序未确认项与本项目验收

“本项目测试通过”只证明 MouseBridge 的选定规则，**不会反向证明 ShareMouse 采用相同规则**。参考分析来自官方 Windows 便携包主程序 7.0.31.0 的静态证据；原用户提供的文件是 UIDownloader 下载器。

## 已有依据

| 机制 | 原分析证据 | 本项目对应实现 |
|---|---|---|
| 全局捕获与本机抑制 | smkey.dll WH_MOUSE_LL，回调 0x41E3F8；接管分支 0x41E676 通知主窗后返回1 | Windows 低级钩子；macOS Event Tap |
| 累计移动后发送 | 主窗 0xA78484 累加位移；0xA75450 定时比较；0xA94BFC 格式化 mousemove | Controller 发送位移；Machine 累计为远端绝对位置；传输采用独立 TLS/TCP 协议 |
| 网络命令到输入注入 | UDP 分发 0xA959E8 → 0xA830E8 → … → 0x740D98 → SendInput | 会话处理 → Machine → Windows SendInput / macOS CGEventPost |
| UDP 发现 | AutoFindTimerTimer 0xA7BC78 → rc_iamhere；原程序默认1046 | 独立的 HMAC 请求/响应；默认42047 |
| 本机线程通信 | DLL 钩子通过 PostMessageW 通知原生 VCL 主窗，不是 renderer IPC | Go 函数调用、锁与有界 channel；无浏览器渲染进程 |

分析报告放在 [research](research/)，完整原始证据保留在本地交付归档。

## 本项目仍需真实环境确认

| 验收项 | 当前状态 | 操作与成功标准 |
|---|---|---|
| Windows → macOS | 待验证 | 真实 `receive -live` / `control -live`；进入、移动、三键、拖动、滚轮、双击与返回符合规格 |
| macOS → Windows | 待验证 | 交换控制端/接收端，重复上一项；远端程序能接收真实注入 |
| macOS权限 | 待验证 | 缺权限明确报错；授权后可创建tap/注入；撤销后可退出，不持续占用鼠标 |
| Windows钩子/输入权限 | 待验证 | 普通窗口工作；目标完整性级别阻止输入时控制端断开/报错；无提权绕过 |
| DPI与多屏 | 主屏方案已实现，真机待验证 | 100%/150%/200%、Retina，验证入口高度和指针速度；多屏布局不在当前规格内 |
| 断网恢复 | 网络模拟通过，双机待验证 | 远端拖动时断开网络；约2秒加调度延迟后A恢复本机、B释放按钮；重跑可连接 |
| 回环抑制 | 待验证 | B无物理输入时无自激移动；A居中/返回注入不会再次触发跨屏 |
| Windows arm64 / Intel Mac | 编译通过，运行待验证 | 在相应机器启动并重复上述矩阵 |
| 长时间与高频鼠标 | 待验证 | 1000Hz鼠标、Wi-Fi拥塞、持续1小时；记录最大延迟和退出情况，不预先宣称指标 |

自动测试替换的是操作系统桌面边界，网络传输是真实的；因此它们不能证明操作系统注入成功。当前交付不标记为完成双机验收的成品。
